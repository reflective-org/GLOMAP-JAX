# GLOMAP-JAX

Differentiable GLOMAP-mode aerosol microphysics in Python/JAX — a faithful port
of the UKCA GLOMAP-mode box model (nucleation, condensation, coagulation,
ageing, mode merging, water uptake).

Work in progress. See `docs/` for the port plan and validation strategy.
